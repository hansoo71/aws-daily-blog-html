핵심 트렌드 분석

1. AI 협업은 SDLC 재설계 문제

CJ올리브영 사례는 AI 코딩 도구의 개인 활용을 넘어 요구사항·설계·구현·검증을 팀 단위로 표준화하는 방향을 제시한다.

2. 에이전트는 런타임/메모리/툴로 분해

Nova Sonic, AgentCore Memory, PTC는 에이전트를 voice UX, persistent memory, managed gateway, sandbox execution으로 나누어 설계해야 함을 보여준다.

3. 데이터 거버넌스는 feature 생성 시점에 내장

SageMaker Feature Store의 Lake Formation·Iceberg 통합은 ML 데이터 플랫폼의 권한·비용 통제를 자동화하는 흐름이다.

4. 차별화 영역만 자체 구축

CIME의 4K 저지연 사례는 매니지드 서비스와 자체 구축을 대립시키지 않고, 차별화 품질 기준에 따라 경계를 설정한다.

에이전트 아키텍처는 이제 모델 호출보다 runtime, memory, tool, sandbox, session boundary 설계가 핵심이다.

리스크·거버넌스 고려사항

  • 메모리 거버넌스: 에이전트 장기 메모리는 사용자/프로젝트 단위 namespace, 삭제 정책, 접근권한, 감사 로그가 필요하다.
  • Sandbox 보안: PTC와 Code Interpreter는 네트워크, 파일시스템, 실행시간, 패키지 설치 범위를 명확히 제한해야 한다.
  • Feature 권한: Feature Store offline data는 Lake Formation 권한과 IAM 혼합 모드를 조직 정책에 맞게 설계해야 한다.
  • 미디어 비용/성능: CloudFront 캐시 키, NAT Gateway warm-up, origin fan-out은 사전 부하 테스트로 검증해야 한다.
