# 이미지 프롬프트 기록

## 이미지 프롬프트 1
- 목적: 핵심 트렌드 히어로 이미지
- 삽입 위치: 히어로 하단
- 이미지 생성 프롬프트: 아마존웹서비스 블로그 기반 클라우드·인공지능 전략 인포그래픽, 한국어 제목과 카드형 시각 요소, 기업 보고서 톤, 16:9
- 권장 비율: 16:9
- 대체 텍스트: 클라우드 변화 신호를 설명하는 전략형 인포그래픽

## 이미지 프롬프트 2
- 목적: 데이터와 인공지능 적용 포인트 시각화
- 삽입 위치: 기술 변화 섹션
- 이미지 생성 프롬프트: 데이터 파이프라인과 생성형 인공지능 적용 포인트를 보여주는 한국어 비즈니스 인포그래픽, 16:9
- 권장 비율: 16:9
- 대체 텍스트: 데이터와 인공지능 적용 포인트를 보여주는 인포그래픽

## 이미지 프롬프트 3
- 목적: 리스크와 거버넌스 고려사항 시각화
- 삽입 위치: 거버넌스 섹션
- 이미지 생성 프롬프트: 보안, 비용, 운영 검토 항목을 연결한 한국어 거버넌스 맵, 임원 블로그 스타일, 16:9
- 권장 비율: 16:9
- 대체 텍스트: 보안 비용 운영 리스크를 정리한 거버넌스 지도
