# Image Prompt 기록

## Image Prompt 1
- 목적: 히어로 하단의 기술 신호 시각화
- 삽입 위치: 본문 초반 시각 자료 영역
- image2 prompt: 한국어 전문 블로그용 추상 일러스트, 클라우드와 데이터 흐름, 실제 로고 없음
- 권장 비율: 3:2
- alt 텍스트: 아마존웹서비스 일일 전략 블로그 시각 자료 1

## Image Prompt 2
- 목적: 기업 적용 검토 포인트 인포그래픽
- 삽입 위치: 기업 적용 관점 섹션
- image2 prompt: 보안, 비용, 데이터, 검증을 표현한 한국어 인포그래픽
- 권장 비율: 3:2
- alt 텍스트: 아마존웹서비스 일일 전략 블로그 시각 자료 2

## Image Prompt 3
- 목적: 리스크와 거버넌스 보조 이미지
- 삽입 위치: 거버넌스 섹션
- image2 prompt: 클라우드 기술 변화가 기업 적용 검토로 이어지는 전문 블로그 이미지
- 권장 비율: 3:2
- alt 텍스트: 아마존웹서비스 일일 전략 블로그 시각 자료 3
